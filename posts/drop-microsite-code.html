Features

Everything you need.
Nothing you don't.

Drop Microsite Code handles the full lifecycle — from AI-generated content to a live public URL — in one step.

AI-Generated HTML

Describe any topic or paste a brief. The agent creates a fully self-contained, polished HTML page tailored to your content.

One-Step GitHub Push

The bundled push_to_github.py script handles GET-then-PUT logic, SHA resolution, and error handling automatically.

Instant GitHub Pages URL

Every pushed file is immediately available at a predictable Pages URL — shareable before you even close the chat.

Zero External Dependencies

All CSS and JS is inlined. No CDN failures, no broken layouts — your microsite looks identical everywhere it's opened.

Update-Safe Commits

Re-publishing an existing file? The script fetches the current SHA and updates cleanly — no force pushes, no conflicts.

Token-Safe Workflow

Your PAT is used only for the API call and never embedded in the HTML content or committed to the repository.

How It Works

Four steps. One result.

The entire workflow runs inside Writer Agent — no local tools required.

01

Describe your topic

Type a brief, a topic name, or paste raw HTML into the Writer Agent chat with the /github-microsite-publisher command.

02

AI builds the HTML

The html skill generates a polished, fully self-contained page with responsive layout, professional typography, and inline styles.

03

Push to GitHub

The bundled script authenticates with your PAT, resolves the target file SHA if it exists, and commits the HTML via the GitHub Contents API.

04

Get your live URL

The agent returns the commit URL, raw file URL, and GitHub Pages URL. Share it instantly — no deploy pipeline required.
